
# Banking System (C++ Runtime Project)

## 📖 Description
A simple console-based banking system developed in C++.  
This project demonstrates the use of **structures, vectors, and runtime memory management** to handle basic banking operations.  
Unlike file-handling projects, this version stores data only in memory (RAM). Once the program exits, all data is cleared.

## 🛠️ Technologies Used
- C++ Programming Language
- STL Vector
- Runtime Data Storage (no file handling)

## 🚀 Features
- Create new account (name, account number, balance)
- Deposit money into an account
- Withdraw money from an account
- Check balance of an account
- Exit the system
